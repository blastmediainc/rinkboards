# V92 — Neo Sans Bold Bands

- Packaging band preview and exported PDF labels now use Neo Sans Bold.
- The supplied font is not included in this ZIP. Place your licensed `FontsFree-Net-NeoSansBoldTR.ttf` file in the same folder as `index.html` when publishing to GitHub Pages.
- The app loads the font for canvas previews and embeds it in band PDFs using jsPDF.
- If the font is missing, band previews/exports show an error rather than silently substitute a font.
- All other features and naming remain as V91.
