# V90 — Original vector logos in Bands

SVG files are stored unchanged in Dropbox and drawn into exported PDFs as SVG vector paths. PDF files are stored unchanged and their first page is embedded as a vector PDF page using PDF-lib. PNG/WEBP remain raster at source resolution. Preview canvas is raster only and does not affect export. Uploading a new logo removes older file formats for that team. Existing V89-converted PNG logos must be reuploaded from the original SVG/PDF to restore vectors.
